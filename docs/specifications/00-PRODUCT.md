# Product Specification

## 목적

사용자의 개인 재무 데이터를 기반으로 주기별 재무 상태를 계산하고,
이전 기간과 비교하며, 규칙 기반 위험 감지와 AI 설명을 제공한다.

## 대상 사용자

- 자신의 자산과 부채를 직접 관리하려는 개인
- 월간 또는 분기별 재무 리뷰가 필요한 사용자
- 투자 판단을 위한 참고 정보를 원하는 사용자

## MVP 기능

- 재무 프로필 관리
- 자산·부채·보유종목 관리
- 재무 지표 계산
- 월간 스냅샷 생성
- 이전 기간 비교
- 규칙 기반 경고
- AI 재무 리뷰 생성
- 과거 리뷰 조회

## 8주 MVP 우선순위

8주 개발에서는 다음을 필수 범위로 둔다.

1. 로컬 재무 프로필 생성
2. 투자 성향 검사
3. 현재 재무 상태 입력
4. 결정론적 재무 지표 계산
5. 규칙 기반 경고 생성
6. 월간 스냅샷 저장과 이전 월 비교
7. AI 기반 결과 설명

복수 추천안과 추가 조건 재분석은 핵심 구조를 먼저 만든 뒤 구현한다.
초기 구현에서는 애플리케이션 규칙과 템플릿으로 추천안을 만들고,
AI는 추천안을 새로 만들지 않고 설명만 담당한다.

## 제외 범위

- 자동매매
- 은행·증권사 계좌 직접 연동
- 실시간 시세
- 세금 계산
- 전문 투자자문
- 수익률 보장

## 성공 기준

사용자가 재무 데이터를 입력하고 월간 스냅샷을 생성하면,
현재 상태와 전월 대비 변화를 확인하고 AI 보고서를 조회할 수 있다.
