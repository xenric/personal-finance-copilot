# AI Report Specification

## 1. 문서 목적

이 문서는 Personal Finance Copilot MVP에서 AI가 생성하는 재무 리뷰 보고서의 역할, 입력, 출력, 금지 사항을 정의한다.

AI 보고서는 계산 결과와 규칙 기반 경고를 설명하는 보조 결과물이다. AI 보고서가 원본 데이터, 계산 결과, 경고 결과를 변경해서는 안 된다.

AI 보고서는 스냅샷 저장 이후 생성하며, 저장된 스냅샷을 `snapshotId`로 참조한다.

---

## 2. AI의 역할

AI가 할 수 있는 일:

- 계산된 재무 지표를 자연어로 설명한다.
- 이전 기간 대비 변화를 요약한다.
- 규칙 기반 경고의 의미를 설명한다.
- 여러 추천안의 장단점과 트레이드오프를 설명한다.
- 사용자가 다음 기간에 확인할 항목을 정리한다.

AI가 하면 안 되는 일:

- 입력 데이터에 없는 금액, 수익률, 확률을 만들어낸다.
- 특정 금융상품의 직접적인 매수·매도 명령을 제공한다.
- 수익률을 보장하거나 손실 가능성을 축소한다.
- 전문 투자자문처럼 단정적인 결론을 제공한다.
- 계산 결과나 경고 상태를 수정한다.
- 세금, 법률, 보험, 대출 승인 가능성을 확정적으로 판단한다.

---

## 3. 입력 데이터

AI 보고서 생성에는 구조화된 데이터만 전달한다.

포함 대상:

- 스냅샷 식별자와 기간
- 사용자 기준 통화
- 계산된 재무 지표
- 계산 불가 항목과 이유
- 규칙 기반 경고
- 이전 기간 비교 결과
- 추천안 목록
- 선택된 추천안 또는 미선택 상태

제외 대상:

- API 키와 비밀값
- 내부 파일 경로
- 불필요한 원본 개인 메모 전문
- AI 설명에 필요 없는 민감정보

---

## 4. 출력 구조

AI 보고서는 다음 구조로 저장한다.

```json
{
  "summary": "",
  "keyChanges": [],
  "positiveSignals": [],
  "warnings": [],
  "goalProgress": [],
  "recommendationReview": [],
  "nextPeriodChecklist": [],
  "unknowns": [],
  "disclaimer": ""
}
```

각 항목은 사용자가 읽을 수 있는 문장 배열 또는 짧은 문단으로 구성한다.

---

## 5. 필수 표현 원칙

- 계산된 수치를 인용할 때는 입력 데이터의 단위와 기간을 함께 표시한다.
- 계산 불가 항목은 이유와 필요한 추가 데이터를 설명한다.
- 추천안은 선택지로 표현하고 실행 명령으로 표현하지 않는다.
- 위험과 트레이드오프를 함께 설명한다.
- 과거 대비 변화는 비교 가능한 항목에 대해서만 설명한다.

---

## 6. 금지 표현

다음 표현은 사용하지 않는다.

- 반드시 매수해야 합니다.
- 반드시 매도해야 합니다.
- 수익이 보장됩니다.
- 손실 위험이 없습니다.
- 이 상품이 최선입니다.
- 세금상 반드시 유리합니다.
- 대출 승인이 가능합니다.

유사하게 단정적인 투자 지시나 보장성 표현도 금지한다.

---

## 7. 실패 처리

AI 호출이 실패하면 다음 원칙을 따른다.

- 재무 계산 결과와 규칙 경고는 그대로 제공한다.
- 스냅샷 저장은 가능해야 한다.
- 보고서 상태를 `FAILED`로 저장한다.
- 사용자가 재시도할 수 있도록 실패 사유의 범주를 제공한다.
- 내부 오류 전문이나 비밀값을 노출하지 않는다.

---

## 8. 버전

MVP의 초기 프롬프트 버전은 다음 값을 사용한다.

```text
promptVersion = "report-prompt-v1"
```
