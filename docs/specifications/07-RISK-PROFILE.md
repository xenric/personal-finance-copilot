# Risk Profile Specification

## 1. 문서 목적

이 문서는 Personal Finance Copilot MVP에서 투자 성향을 결정론적으로 산정하기 위한 질문, 점수, 결과 타입을 정의한다.

AI는 투자 성향을 산정하지 않는다.
AI는 이미 산정된 투자 성향과 근거를 설명할 수만 있다.

---

## 2. 결과 타입

MVP에서는 다음 세 가지 투자 성향만 사용한다.

| 결과 | 설명 |
| ---- | ---- |
| CONSERVATIVE | 안정성과 유동성을 우선한다. |
| BALANCED | 안정성과 장기 성장의 균형을 우선한다. |
| GROWTH | 장기 성장과 변동성 감수를 우선한다. |

---

## 3. 질문과 점수

각 질문은 0점부터 2점까지 부여한다.

### 투자 기간

| 선택지 | 점수 |
| ------ | ---: |
| 2년 미만 | 0 |
| 2년 이상 5년 미만 | 1 |
| 5년 이상 | 2 |

### 손실 감수

| 선택지 | 점수 |
| ------ | ---: |
| 원금 손실 가능성을 거의 감수하기 어렵다 | 0 |
| 일시적 손실은 일부 감수할 수 있다 | 1 |
| 장기 목표를 위해 큰 변동성도 감수할 수 있다 | 2 |

### 유동성 필요

| 선택지 | 점수 |
| ------ | ---: |
| 1년 안에 큰 지출 가능성이 높다 | 0 |
| 1년에서 3년 안에 큰 지출 가능성이 있다 | 1 |
| 3년 안에 큰 지출 계획이 낮다 | 2 |

### 투자 경험

| 선택지 | 점수 |
| ------ | ---: |
| 투자 경험이 거의 없다 | 0 |
| 예금, ETF, 펀드 등 일부 경험이 있다 | 1 |
| 주식, ETF, 채권 등 여러 자산 경험이 있다 | 2 |

### 하락장 대응

| 선택지 | 점수 |
| ------ | ---: |
| 즉시 대부분 매도할 가능성이 높다 | 0 |
| 일부 조정하되 계획을 다시 확인한다 | 1 |
| 장기 계획에 따라 유지하거나 재조정한다 | 2 |

---

## 4. 산정 규칙

총점은 0점부터 10점까지다.

| 총점 | 투자 성향 |
| ---- | --------- |
| 0-3 | CONSERVATIVE |
| 4-7 | BALANCED |
| 8-10 | GROWTH |

필수 질문에 답변하지 않으면 투자 성향을 계산하지 않고 `INSUFFICIENT_DATA`로 처리한다.

---

## 5. 저장 정보

투자 성향 결과에는 다음 정보를 저장한다.

| 항목 | 설명 |
| ---- | ---- |
| result | 투자 성향 결과 |
| score | 총점 |
| answers | 질문별 선택지와 점수 |
| assessedAt | 산정 시각 |
| assessmentVersion | 산정 규칙 버전 |

---

## 6. 버전

MVP의 초기 투자 성향 산정 버전은 다음 값을 사용한다.

```text
assessmentVersion = "risk-profile-v1"
```
