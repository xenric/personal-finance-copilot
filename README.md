# personal-finance-copilot
A personal project exploring AI-assisted personal finance reviews, portfolio tracking, and personalized investment insights for better financial decisions.

## Development Stack

This project will be implemented with Java.

Recommended MVP stack:

- Java 25
- Spring Boot 4.1
- Thymeleaf
- Gradle
- JUnit 5
- Jackson
- Jakarta Bean Validation

## UI Direction

The first MVP will use Spring Boot with Thymeleaf for server-rendered pages.

This keeps the initial project as a single Java application and avoids adding a separate frontend build pipeline too early. The UI should focus on the core workflow:

1. Create a financial profile and goals
2. Enter income, expenses, assets, liabilities, and investment asset details
3. Calculate financial metrics
4. Generate rule-based warnings
5. Create and compare monthly snapshots
6. Generate an AI-assisted review report

Investment holdings are represented in the domain as `Asset` records with optional investment details such as symbol, quantity, unit price, and market. Storage may later use a separate holdings file, but domain calculations should work from assets.

If the product later needs a richer frontend, the UI can be split into a React or TypeScript client after the core domain, storage, and analysis flows are stable.

## MVP Scope Notes

The first 8-week MVP should prioritize:

1. Local profile and risk profile setup
2. Current financial state input
3. Deterministic metric calculation
4. Rule-based warnings
5. Monthly snapshot storage and comparison
6. AI-assisted explanation of calculated results

Recommendation options should be generated by application rules and templates first. AI may explain those options, but it should not independently create financial instructions.
